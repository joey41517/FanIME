# Recon：超注音 3.5.6（tw.chaozhuyin）— 扇形與符號表

- 裝置：Samsung SM-S9310 / Android 16 / 1080x2340
- 測試環境：Google Keep 空白記事
- 方法：adb 截圖 + `input motionevent` 模擬按住和拖曳
- `uiautomator dump` 抓不到鍵盤元件（鍵盤是自繪 View），所以只能靠截圖觀察

## 主鍵盤（注音模式，01-keyboard.png）
- 工具列：設定 / 語音 / 繁 / ← / → / 剪貼簿 / 收鍵盤
- 4 列標準注音排列，含聲調鍵 ˇˋˊ˙
- 底列：**ABC（中英切換，最常用）** / **風車鍵（扇形）** / 標點 / 空白 / 。/ ㄦ / 刪除 / Enter
- 主要使用情境是中英混打，扇形負責「偶爾要用的其他字元」

## 扇形（03-pinwheel-hold.png）
| 操作 | 結果 |
|---|---|
| 輕點風車鍵 | 沒有反應 |
| 按住約 1 秒 | 從風車鍵中心放射出 7 個選項，半透明，蓋在注音鍵上 |
| 按住後不滑動、直接放開 | 取消 |
| 按住 → 滑向某個選項 → 放開 | 開啟該選項的符號表 |

選項從左上到右（相鄰約差 15°，整個扇形約 90°）：

半 / 全 / 數 / :-) / 😀 / ① / あ

## 符號表的共同結構（あ、半、全 都一樣）
- 8 欄 × 4 列的字元格，右側 ↓ 鍵翻頁
- 底列：**返回**（回到注音）/ 該表專屬的幾個字元 / 刪除 / **釘選**
- 釘選的作用可能是「點一個字之後不要自動回注音」，還沒驗證

## 使用者回饋（entrepreneur）
- 最常用的是中英切換（ABC 鍵），其次是半形表、全形表，再來是 Emoji
- 在其他輸入法要打半形符號：切到英文 → 打符號 → 再一路切回原本的語言，非常麻煩。超注音的符號表打一個字就好
- **日文太難用**：使用者習慣羅馬拼音，假名表只能一個一個點
- ① 幾乎不用，可以換成**韓文**
- 「數」只在網頁數字欄位或撥電話時自動跳出，使用者不會從扇形手動切過去
- 顏文字太單調，希望可以**自己編輯清單**
